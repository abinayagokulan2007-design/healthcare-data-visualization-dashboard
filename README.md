# Healthcare Data Visualization Dashboard

## 📊 Project Overview

This project presents an interactive healthcare data visualization dashboard created using Tableau. The dashboard analyzes patient records, medical conditions, admission types, test results, insurance providers, billing amounts, patient age, and hospital length of stay.

The objective of this project is to transform healthcare data into meaningful visual insights that can help users understand patient demographics, healthcare utilization, and billing patterns.

## 🛠️ Tools Used

- Tableau
- Microsoft Excel / CSV Dataset
- GitHub

## 📌 Key Performance Indicators

The dashboard includes the following KPIs:

- Total Patients: 55,500
- Average Billing Amount: 25,539.32
- Average Patient Age: 51.54 years
- Average Length of Stay: 15.51 days

## 📈 Visualizations

The dashboard contains visualizations for:

- Patients by Medical Condition
- Patients by Age Group
- Patients by Admission Type
- Patients by Test Result
- Patients by Insurance Provider
- Average Billing by Medical Condition
- Average Length of Stay by Medical Condition

## 🔍 Key Insights

- The dataset contains 55,500 healthcare records.
- The average patient age is 51.54 years.
- The average hospital stay is 15.51 days.
- The average billing amount is 25,539.32.
- Patient records are distributed across different medical conditions, admission types, test results, and insurance providers.
